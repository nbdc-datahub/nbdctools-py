		<h1>nbdctools</h1>

		<div class="intro">
			<p>
				This Python package provides tooling for working with tabulated data released by the
				<a href="https://www.nbdc-datahub.org/">NIH Brain Development Cohorts (NBDC) Data Hub</a>
				for the ABCD and HBCD studies.
			</p>

			<p>
				The package is designed to help researchers and data analysts create integrated
				datasets from tabulated data files. Building on the R package <a href="https://software.nbdc-datahub.org/NBDCtools/">NBDCtools</a>,
				it provides a thin wrapper around the core R functionality, and a simplified pure-Python
				alternative for users who prefer to work in Python without an R installation.
			</p>
		</div>
