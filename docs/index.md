		<h1>nbdctools</h1>

		<div class="intro">
			<p>
				This Python package provides tooling for working with data released by the
				<a href="https://www.nbdc-datahub.org/">NIH Brain Development Cohorts (NBDC) Data Hub</a>,
				for ABCD/HBCD and related tabulated datasets.
			</p>

			<p>
				The package is designed to help researchers and data analysts create integrated
				datasets from tabulated data files. Proceeding from R package <a href="https://software.nbdc-datahub.org/NBDCtools/">NBDCtools</a>,
				this Python implementation provides a thin wrapper around the core R functionality while also offering a pure-Python
				simplified alternative for users who prefer to work in Python without R dependencies.
			</p>
